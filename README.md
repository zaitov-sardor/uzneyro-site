# uzneyro.uz

Landing page for UzNeyro, a language-learning project for Uzbek speakers:

- **UzNeyro RU**: Russian, https://www.instagram.com/uzneyroru/
- **UzNeyro EDU (EN)**: English, https://www.instagram.com/uzneyro_en/ and Telegram bot https://t.me/uzneyroenbot

One static file, `index.html`, with inline CSS and JS. The only external resource is the Nunito font from Google Fonts. Interface languages: Uzbek (Latin, default) and Russian. Uzbek text is in the HTML, Russian is in `data-ru` attributes, and the UZ/RU switch in the top bar swaps them.

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
