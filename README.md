# uzneyro.uz

Landing page for UzNeyro, a language-learning project for Uzbek speakers:

- **UzNeyro RU**: Russian, https://www.instagram.com/uzneyroru/
- **UzNeyro EDU (EN)**: English, https://www.instagram.com/uzneyro_en/ and Telegram bot https://t.me/uzneyroenbot

One static file, `index.html`, with inline CSS and JS. External resources: the Montserrat and Inter fonts from Google Fonts, and photos hotlinked from images.unsplash.com under the free Unsplash license. Brand colours come from the UzNeyro EN avatar and posts: violet `#6c4be0`, yellow `#ffc23d`, lime `#c8f43c`, and the RU green `#0f3d2e`. The mascot in the header is a redrawn approximation of the avatar; replace it with the original file when available. Interface languages: Uzbek (Latin, default) and Russian. Uzbek text is in the HTML, Russian is in `data-ru` attributes, and the UZ/RU switch in the top bar swaps them.

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
